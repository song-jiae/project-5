# 🎬 MovieBox - 당신만의 영화와 TV 프로그램 탐색기 🍿

안녕하세요!  
**MovieBox**는 TMDB API를 기반으로 영화와 TV 프로그램 정보를 검색하고, 찜 목록을 관리하며, 멋진 정보를 제공하는 귀여운 앱이에요. 😻  
"오늘 뭐 보지?"라는 고민을 덜어줄 친구랍니다! 💡

## 🎁 주요 기능
- 🎥 **영화 검색 및 필터링**: 인기 영화, 높은 평점 순 등 원하는 영화 찾기!
- 📺 **TV 프로그램 탐색**: 방영 중인 프로그램도 한눈에 확인!
- ❤️ **찜 기능**: 내가 좋아하는 콘텐츠 저장하기.
- 🔍 **키워드로 검색**: 영화 제목이나 배우 이름으로 바로 검색!
- 🎞️ **트레일러 보기**: 트레일러로 미리 보기 가능!
